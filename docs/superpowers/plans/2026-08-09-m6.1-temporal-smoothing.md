---

**Goal:** Add an across-frame histogram EMA before the display pipeline to kill low-spp export flicker, preserving determinism, Metal↔CPU parity, and animate↔export byte-identity.

**Architecture:** `H_acc = (1−α)·H_acc_prev + α·H_current` on the Double `Histogram`, then DE + log-density + tone-map run once on `H_acc`. The accumulator is owned by `ExportCoordinator`. CPU gets the pre-DE histogram from a new `ReferenceRenderer.histogram(...)` split; Metal reuses fused chaos but reads `atomicBuf` back + host-decodes it (the proven `ChaosGameMetal.decode`, extracted `nonisolated`) + runs DE/display off-main. Smoothing is OFF (α=1.0) on the mastering path and at genome-default, so the existing fused path and every animate↔export pin are byte-unchanged. Resume reconstructs `H_acc` bit-identically via full-window warmup `[0,F)`.

**Tech Stack:** Swift 6, Metal 4, Foundation. Apple SDKs only. No new `.metal` shader.

**User decisions (already made — do not re-litigate):**
- D1: Metal via fused-chaos + `atomicBuf` readback + host decode (not a GPU EMA kernel, not the non-fused alternative).
- D2: EMA on the pre-DE histogram; DE+display run once on `H_acc`.
- D3 + α-ramp: α = 1.0 (OFF/genome-default); else a **continuous log-linear ramp** through anchors `(spp→α): (2,0.10),(8,0.20),(30,0.35),(64,1.0)`, clamped `[0.10,1.0]`.
- D4: OFF when α≥1.0 OR mastering path; `renderImage` OFF branch byte-identical.
- D5: additive Metal variants; existing fused cores + realtime/thumbnail byte-unchanged.
- D6: accumulator continuous across a run, fed in rendered-global-frame order.
- D7 / P1.5a: on resume, full-window warmup `[0,F)` (re-render histograms, discard images); `H_acc` NOT serialized.
- D8: smoothing lives on `ExportSettings` (Codable; rides in checkpoint via `settings`).
- D9: export-only; realtime `PlaybackDispatcher` untouched.
- CPU + resume + smoothing: **warn at resume** ("CPU warmup may take ~X min"); no hard guard.

// Sources/FlameExport/HistogramEMA.swift
import Foundation
import FlameKit

/// Across-frame histogram EMA (M6.1 slice 2, spec §3.1). Pure + deterministic
/// (rule #2: iterates contiguous `Histogram` arrays — no Dict/Set float sums).
/// Shared by the CPU and Metal smoothing paths (both produce/consume a Double
/// `Histogram`).
public enum HistogramEMA {
    /// In-place EMA `acc = (1−α)·acc + α·current`. Cold start (`acc == nil`) ⇒
    /// `acc = current` (the first rendered frame is shown sharp; pinned
    /// byte-equal to the OFF path for frame 0, spec §6.2). α = 1.0 ⇒ `acc`
    /// becomes `current` exactly (OFF equivalence).
    public static func update(_ acc: inout Histogram?, current: Histogram, alpha: Double) {
        if acc == nil { acc = current; return }
        // Mutate the wrapped value in place (S3: avoids a full-Histogram copy-out +
        // copy-back on every call — ~2×332 MB at 4K otherwise). `acc!` on the LHS
        // mutates the optional's wrapped value through the `inout`.
        precondition(acc!.colors.count == current.colors.count
                     && acc!.alpha.count == current.alpha.count
                     && acc!.counts.count == current.counts.count,
                     "HistogramEMA.update: grid dimension mismatch")
        let oneMinusA = 1.0 - alpha
        for i in acc!.colors.indices {
            acc!.colors[i] = acc!.colors[i] * oneMinusA + current.colors[i] * alpha
            acc!.alpha[i]  = acc!.alpha[i]  * oneMinusA + current.alpha[i]  * alpha
            acc!.counts[i] = acc!.counts[i] * oneMinusA + current.counts[i] * alpha
        }
    }
}
```

// Sources/FlameExport/TemporalSmoothing.swift
import Foundation

/// User-facing temporal-smoothing choice (M6.1 slice 2). `.auto` derives α from
/// the export quality (the continuous ramp); `.off` forces α = 1.0 (byte-
/// identical to the unsmoothed path). Codable + Sendable; a field on
/// `ExportSettings`, so it rides in the checkpoint via `settings`.
public enum TemporalSmoothing: String, Codable, Sendable, CaseIterable, Equatable {
    case auto, off

    /// Resolved EMA weight α ∈ (0, 1] for a quality. `.off` or `.genome` ⇒ 1.0
    /// (OFF). Otherwise the continuous ramp (owner choice 2026-08-09).
    public func alpha(for quality: ExportQuality) -> Double {
        switch (self, quality) {
        case (.off, _), (_, .genome): return 1.0
        case (.auto, .spp(let n)):    return Self.rampAlpha(spp: n)
        }
    }

    /// Continuous log-linear ramp through anchors `(spp, α) = (2,0.10),
    /// (8,0.20), (30,0.35), (64,1.0)`, clamped to `[0.10, 1.0]`. Monotone,
    /// deterministic (rule #2). The anchors match the GUI named tiers exactly
    /// (Low/Med/High at spp 2/8/30), so GUI and CLI agree there; smoothing
    /// ramps to OFF (1.0) by spp=64.
    public static func rampAlpha(spp n: Int) -> Double {
        let anchors: [(spp: Int, alpha: Double)] = [(2, 0.10), (8, 0.20), (30, 0.35), (64, 1.0)]
        if n <= 2 { return 0.10 }
        if n >= 64 { return 1.0 }
        for i in 0..<(anchors.count - 1) {
            let (s1, a1) = anchors[i]
            let (s2, a2) = anchors[i + 1]
            if n <= s2 {
                let t = (log2(Double(n)) - log2(Double(s1))) / (log2(Double(s2)) - log2(Double(s1)))
                return a1 + (a2 - a1) * t
            }
        }
        return 1.0   // unreachable: n >= 64 handled above
    }
}
```
