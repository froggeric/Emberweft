---

**Goal:** Add a local pre-rendered archive of loop/edge videos (HEVC Main10 `.mov`, ES-inspired 4-field naming) plus Path A (Generate) and Path B (Stitch) so a long video composes in seconds once material is cached, and decouple one-shot export from the playback windows.

**Architecture:** A new `FlameFlock` module (sibling to `FlameExport`) owns the catalog (`flock.sqlite`), naming, coordinators, and an `ArchiveRenderer` that builds a per-unit `FramePlan` (1-segment loop, or 2-segment edge emitting only the transition slot — §4.1) and drives two small additive `public` surfaces on `ExportCoordinator` (`renderSegmentRange`, `concat`) that wrap the existing `private` render/concat primitives, keeping the per-frame path single-sourced. The archive codec is HEVC Main10 in `.mov`; each segment is a fresh independent encode (IDR at frame 0), concatenated losslessly via `AVMutableComposition` passthrough. Determinism is a SHA-256-truncation seed over a canonical key string. No engine file (`Sources/FlameKit|FlameReference|FlameRenderer`) is touched; animate↔export byte-identity pins stay green.

**Tech Stack:** Swift 6, Metal 4, AVFoundation, CoreMedia, CryptoKit, **`import SQLite3`** (the system `libsqlite3` shipped with the macOS SDK — *not* a SwiftPM dependency; linked via `linkerSettings: [.linkedLibrary("sqlite3")]` on the `FlameFlock` target). Apple SDKs only (rule #4 honored). SwiftUI/AppKit for the UI.

**User decisions (already made — do not re-litigate):** D1 naming `<a_gen>=<a_id>=<b_gen>=<b_id>.<ext>`, loop = self-edge; D2 cache key `(shard,a_gen,a_id,b_gen,b_id)`; D3 shard dir `WxH_fps` (+ `_Lf-Tf` iff non-canonical); D4 upgrade-overwrite by `quality_rank`; D5 `flock.sqlite` source of truth, rebuildable; D6 thumbnails `<shard>/jpeg/…`; D7 reserved flock `900000` for minted ids; D8 `AppPreferences.flockDir`; D9 dedicated Flock sidebar + decouple export from playback; D10 Path A default scope = edges; D11 standalone M6.5; **D12 archive codec = HEVC Main10 / `.mov`**.

```swift
// Sources/FlameExport/ExportCoordinator.swift — inside the actor body.
//
// M6.5 archive render-range entry (spec §14.2). PUBLIC wrapper around the private
// renderFrames/renderImage primitives so FlameFlock renders a FramePlan range through
// the SAME 3-branch Metal/CPU dispatch (single-sourced parity/byte-identity). The
// existing runJob/runResumable paths do NOT call this — they keep their own encoders.
// `smoothingAlpha >= 1.0` (default/OFF) ⇒ byte-identical to the export OFF path.
public func renderSegmentRange(
    plan: FramePlan,
    params: RenderParams,
    budget: MetalRenderer.ThreadSeedBudget?,
    useMetal: Bool,
    range: Range<Int>,
    smoothingAlpha: Double,
    settings: ExportSettings,
    out: URL,
    metadata: [AVMetadataItem] = []
) async throws {
    let tempURL = out.deletingLastPathComponent()
        .appendingPathComponent("." + out.lastPathComponent + ".partial")
    try? FileManager.default.removeItem(at: tempURL)
    let encoder = try VideoEncoder(settings: settings, outputURL: tempURL, metadata: metadata)
    try await encoder.start()
    // renderFrames already branches on smoothingAlpha (OFF ⇒ renderImage per frame;
    // ON ⇒ feed-emit). yield is a no-op — the ArchiveCoordinator reports its own
    // per-unit progress.
    try await renderFrames(plan: plan, params: params, budget: budget, useMetal: useMetal,
                           range: range, smoothingAlpha: smoothingAlpha,
                           into: encoder, yield: { _ in })
    try await encoder.finish()
    // Rename partial -> out. For a FRESH artifact (no existing file) this is a
    // clean atomic move. For an UPGRADE-overwrite (existing file present) the
    // remove-then-move has a narrow window where `out` is absent; prefer
    // `FileManager.replaceItemAt(out, withItemAt: tempURL)` (uses renamex_np
    // REPLACE — atomic overwrite) when `out` exists. The catalog upsert happens
    // in ArchiveRenderer.renderIntoArchive AFTER this returns, so the invariant
    // "never upsert a row for a missing file" holds regardless. A crash in the
    // remove→move window on an upgrade leaves the OLD row pointing to a gone
    // file; `flock rebuild` recovers (file-not-found ⇒ skip).
    if FileManager.default.fileExists(atPath: out.path) {
        _ = try FileManager.default.replaceItemAt(out, withItemAt: tempURL)
    } else {
        try FileManager.default.moveItem(at: tempURL, to: out)
    }
}
```

```swift
// Sources/FlameFlock/FlockSeed.swift
import Foundation
import CryptoKit

/// Deterministic per-artifact seed (spec §10). SHA-256 over the canonical UTF-8
/// string, first 8 bytes little-endian ⇒ UInt64. Pure string→Int hash (no Swift
/// Dict/Set iteration ⇒ rule-#2-safe). Same artifact + same RenderSpec ⇒ identical
/// bytes, run-to-run and machine-to-machine. Threaded into RenderParams.seed and
/// ThreadSeedBudget(baseSeed:), matching the export invariant.
public enum FlockSeed {
    /// `canonical` = "shard|aGen|aId|bGen|bId" (caller builds in that fixed order).
    public static func sha256ToUInt64(canonical: String) -> UInt64 {
        let digest = SHA256.hash(data: Data(canonical.utf8))
        let bytes = Array(digest)             // 32 bytes
        // First 8 bytes, little-endian.
        var v: UInt64 = 0
        for i in 0..<8 { v |= UInt64(bytes[i]) << (8 * i) }
        return v
    }
    /// Convenience: build the canonical string and hash in one call.
    public static func seed(shard: String, aGen: String, aId: String,
                            bGen: String, bId: String) -> UInt64 {
        sha256ToUInt64(canonical: "\(shard)|\(aGen)|\(aId)|\(bGen)|\(bId)")
    }
}
```

```swift
// Sources/FlameFlock/FlockNaming.swift
import Foundation

public enum FlockNamingError: Error, Equatable { case badShardName(String), escapesRoot }

public enum FlockNaming {
    private static let shardRegex = try! NSRegularExpression(pattern: "^[A-Za-z0-9_]+$")
    private static let digitRegex = try! NSRegularExpression(pattern: "^[0-9]+$")

    /// `<aGen>=<aId>=<bGen>=<bId>.<ext>` (ext excludes the dot). Minted ids are
    /// zero-padded to 6 digits; ES ids preserved verbatim (D1, §5.2).
    public static func fileName(aGen:String, aId:String, bGen:String, bId:String, ext:String) -> String {
        let pad = { (s: String, width: Int) -> String in
            // Pad only purely-numeric, sub-width strings (ES ids like "00628" pass through; "18169" too).
            guard s.count < width, self.digitRegex.firstMatch(in:s, range: NSRange(location:0,length:s.utf16.count)) != nil else { return s }
            return String(repeating: "0", count: width - s.count) + s
        }
        return "\(aGen)=\(pad(aId,6))=\(bGen)=\(pad(bId,6)).\(ext)"
    }

    public static func isLoop(aGen:String,aId:String,bGen:String,bId:String) -> Bool {
        aGen == bGen && aId == bId
    }

    /// Split stem on `=`; require exactly 4 numeric fields. nil ⇒ skip + log.
    public static func decode(stem:String) -> (aGen:String,aId:String,bGen:String,bId:String)? {
        let parts = stem.split(separator: "=").map(String.init)
        guard parts.count == 4, parts.allSatisfy({ digitRegex.firstMatch(in:$0, range: NSRange(location:0,length:$0.utf16.count)) != nil }),
              !parts.contains(where: { $0.contains("..") || $0.contains("/") }) else { return nil }
        return (parts[0], parts[1], parts[2], parts[3])
    }

    /// `WxH_fps` + `_Lf<loop>-Tf<trans>` iff non-canonical (D3). Canonical pace =
    /// loopFrames==round(15*fps) && transFrames==round(12*fps).
    public static func shardDir(width:Int, height:Int, fps:Int,
                                loopFrames:Int, transFrames:Int,
                                canonicalLoopSeconds:Double = 15.0,
                                canonicalTransSeconds:Double = 12.0) throws -> String {
        let base = "\(width)x\(height)_\(fps)fps"
        let cl = Int((canonicalLoopSeconds * Double(fps)).rounded())
        let ct = Int((canonicalTransSeconds * Double(fps)).rounded())
        return (loopFrames == cl && transFrames == ct)
            ? base : "\(base)_Lf\(loopFrames)-Tf\(transFrames)"
    }

    /// Path-safety-checked archive file URL. Shard validated to `^[A-Za-z0-9_]+$`;
    /// resolved path checked inside `flockRoot` (mirrors BatchPath.resolve, §5.2).
    public static func archiveFileURL(flockRoot:URL, shardDir:String,
                                      aGen:String,aId:String,bGen:String,bId:String,
                                      ext:String) throws -> URL {
        try validateShard(shardDir)
        let file = fileName(aGen:aGen,aId:aId,bGen:bGen,bId:bId,ext:ext)
        let target = flockRoot.resolvingSymlinksInPath()
            .appendingPathComponent(shardDir)
            .appendingPathComponent("mpeg")
            .appendingPathComponent(file)
        try ensureInside(flockRoot: flockRoot, target: target)
        return target
    }
    public static func thumbURL(flockRoot:URL, shardDir:String,
                                aGen:String,aId:String,bGen:String,bId:String) throws -> URL {
        try validateShard(shardDir)
        let file = fileName(aGen:aGen,aId:aId,bGen:bGen,bId:bId,ext:"jpg")
        let target = flockRoot.resolvingSymlinksInPath()
            .appendingPathComponent(shardDir)
            .appendingPathComponent("jpeg")
            .appendingPathComponent(file)
        try ensureInside(flockRoot: flockRoot, target: target)
        return target
    }

    /// Public predicate (used by `FlockCatalog.rebuild` to filter shard dirs).
    public static func isValidShardName(_ s: String) -> Bool {
        !s.contains("/") && !s.contains("..") &&
        shardRegex.firstMatch(in: s, range: NSRange(location: 0, length: s.utf16.count)) != nil
    }
    private static func validateShard(_ s:String) throws {
        // Reject anything containing path separators BEFORE the regex (the regex is
        // `^…$` so it already rejects '/', but `..`/subdirs need an explicit check).
        guard isValidShardName(s) else { throw FlockNamingError.badShardName(s) }
    }
    private static func ensureInside(flockRoot:URL, target:URL) throws {
        let root = flockRoot.resolvingSymlinksInPath().standardizedFileURL.path
        let tgt = target.resolvingSymlinksInPath().standardizedFileURL.path
        guard tgt.hasPrefix(root + "/") || tgt == root else { throw FlockNamingError.escapesRoot }
    }
}
```

```swift
// Sources/FlameFlock/SQLiteConnection.swift
import Foundation
import SQLite3

/// Minimal system-sqlite3 wrapper (open/prepare/step/bind/column/finalize). One
/// serialized writer via FlockCatalog's actor isolation ⇒ no SQLITE_BUSY. The macOS
/// SDK ships libsqlite3; linked via Package.swift `linkerSettings: [.linkedLibrary("sqlite3")]`.
final class SQLiteConnection: @unchecked Sendable {
    private var db: OpaquePointer?
    /// `readOnly: true` opens via `sqlite3_open_v2(..., SQLITE_OPEN_READONLY)` (used by
    /// `EdgePairsOracle` over the ES archive `edges.sqlite` — never writes). Default
    /// `false` opens read-write (used by `FlockCatalog`).
    init(_ url: URL, readOnly: Bool = false) throws {
        if readOnly {
            if sqlite3_open_v2(url.path, &db, SQLITE_OPEN_READONLY, nil) != SQLITE_OK {
                throw FlockCatalogError.openFailed
            }
        } else {
            if sqlite3_open(url.path, &db) != SQLITE_OK { throw FlockCatalogError.openFailed }
            sqlite3_exec(db, "PRAGMA journal_mode=WAL;", nil, nil, nil)
            sqlite3_exec(db, "PRAGMA synchronous=NORMAL;", nil, nil, nil)
        }
    }
    deinit { sqlite3_close(db) }

    func exec(_ sql: String) throws {
        var err: UnsafeMutablePointer<CChar>?
        if sqlite3_exec(db, sql, nil, nil, &err) != SQLITE_OK {
            let msg = err.map { String(cString: $0) } ?? "?"; sqlite3_free(err)
            throw FlockCatalogError.execFailed(msg)
        }
    }
    @discardableResult
    func run(_ sql: String, _ params: [SQLiteBindable] = []) throws -> Int {
        var stmt: OpaquePointer?
        if sqlite3_prepare_v2(db, sql, -1, &stmt, nil) != SQLITE_OK {
            throw FlockCatalogError.prepareFailed(String(cString: sqlite3_errmsg(db)))
        }
        defer { sqlite3_finalize(stmt) }
        for (i, p) in params.enumerated() { try p.bind(to: stmt, at: Int32(i + 1)) }
        let rc = sqlite3_step(stmt)
        if rc != SQLITE_DONE && rc != SQLITE_ROW {
            throw FlockCatalogError.stepFailed(String(cString: sqlite3_errmsg(db)))
        }
        return Int(sqlite3_changes(db))
    }
    func query(_ sql: String, _ params: [SQLiteBindable] = []) throws -> SQLiteCursor {
        var stmt: OpaquePointer?
        if sqlite3_prepare_v2(db, sql, -1, &stmt, nil) != SQLITE_OK {
            throw FlockCatalogError.prepareFailed(String(cString: sqlite3_errmsg(db)))
        }
        for (i, p) in params.enumerated() { try p.bind(to: stmt, at: Int32(i + 1)) }
        return SQLiteCursor(stmt: stmt)
    }
}
protocol SQLiteBindable { func bind(to stmt: OpaquePointer?, at idx: Int32) throws }
extension String: SQLiteBindable { func bind(to s: OpaquePointer?, at i: Int32) throws {
    sqlite3_bind_text(s, i, self, -1, unsafeBitCast(-1, to: sqlite3_destructor_type.self)) } }
extension Int: SQLiteBindable { func bind(to s: OpaquePointer?, at i: Int32) throws {
    sqlite3_bind_int64(s, i, sqlite3_int64(self)) } }
extension Double: SQLiteBindable { func bind(to s: OpaquePointer?, at i: Int32) throws {
    sqlite3_bind_double(s, i, self) } }
extension Int?: SQLiteBindable { func bind(to s: OpaquePointer?, at i: Int32) throws {
    if let v = self { try v.bind(to: s, at: i) } else { sqlite3_bind_null(s, i) } } }
extension String?: SQLiteBindable { func bind(to s: OpaquePointer?, at i: Int32) throws {
    if let v = self { try v.bind(to: s, at: i) } else { sqlite3_bind_null(s, i) } } }

final class SQLiteCursor {
    let stmt: OpaquePointer?; var done = false
    init(stmt: OpaquePointer?) { self.stmt = stmt }
    func next() -> Bool { done = (sqlite3_step(stmt) != SQLITE_ROW); return !done }
    func text(_ i: Int32) -> String { sqlite3_column_text(stmt, i).map { String(cString: $0) } ?? "" }
    func int(_ i: Int32) -> Int { Int(sqlite3_column_int64(stmt, i)) }
    func double(_ i: Int32) -> Double { sqlite3_column_double(stmt, i) }
    func isNull(_ i: Int32) -> Bool { sqlite3_column_type(stmt, i) == SQLITE_NULL }
    deinit { sqlite3_finalize(stmt) }
}
```

```swift
import Foundation
import CryptoKit

public struct IdMinter {
    public init() {}

    /// Resolve a genome to its stable `(gen,id)`. ES-sourced ⇒ passthrough; anything
    /// else ⇒ mint in flock 900000, deduped on `sourceSha` (§7). Idempotent: minting
    /// the same source twice returns the same id.
    public func resolve(catalog: FlockCatalog, esGen: String?, esId: String?, origin: Sheep.Origin,
                        sourceRef: URL?, sourceBytes: Data?) async throws -> (gen: String, id: String) {
        if origin == .es, let g = esGen, let i = esId { return (g, i) }   // ES passthrough
        let sha = (sourceBytes.map { SHA256.hash(data: $0) }.map { $0.map { String(format: "%02x", Int($0)) }.joined() }) ?? ""
        // Dedupe on source_sha: if a sheep row with this sha exists, reuse its (gen,id).
        if let existing = try await findBySourceSha(catalog: catalog, sha: sha) { return existing }
        let id = try await catalog.nextMintedId()
        try await catalog.upsertSheep(gen: "900000", id: id, origin: origin,
                                      sourceRef: sourceRef, sourceSha: sha, displayName: nil)
        return ("900000", id)
    }

    private func findBySourceSha(catalog: FlockCatalog, sha: String) async throws -> (String,String)? {
        // Read-only lookup by source_sha (a small helper SQL on the catalog; add a
        // `func sheepBySourceSha(_:) async throws -> Sheep?` to FlockCatalog if missing).
        try? await catalog.sheepBySourceSha(sha).map { ($0.gen, $0.id) }
    }
}
```

### Task 9: `ArchiveRenderer` — lone-edge `FramePlan` + atomic write + tags + thumb

**Goal:** Render one loop OR one edge unit into an archive-named HEVC `.mov` + `.jpg` thumb + `[AVMetadataItem]` tags via `renderSegmentRange` (T2). The edge uses the **2-segment plan emitting only the transition slot** (§4.1, I9); `ExportCheckpoint.sanitizedStem` is bypassed; write order is **temp → atomic rename → catalog upsert** (never a row without its file).

> **Smoothing-ON byte-identity caveat (verified against `renderFrames`, ExportCoordinator.swift:254-334):** the spec's §4.1 "the archive's edge byte-matches the edge rendered inline in a one-shot export" holds for **smoothing OFF** (the mastering/default path — `renderImage` per frame, identical inputs ⇒ identical RGBA). For **smoothing ON** (`halfWidth > 0`), `renderFrames` gates on `plan.totalFrames > 1` and feeds the centered box window via `feedEmitSmoothed(encodeRange: range)`. The 2-segment edge plan's lookahead clips at `plan.totalFrames = loopFrames + transFrames` (no segment-2 loop(B) lookahead), so the **trailing transition frames** (within `h` of the end) average a clipped window, while an inline edge in a full `[loop A, trans A→B, loop B]` plan sees loop(B) lookahead. The leading transition frames match (lookback is loop(A) in both). Net: the smoothing-ON standalone edge is **deterministic** (run-to-run stable — same plan, same window, same bytes) and the **stitch is stable** (same sequence ⇒ same pre-baked segments ⇒ same concat), but it is NOT byte-identical to a one-shot smoothing-ON export at the trailing frames. This is acceptable: stitch is a remux path (it never re-renders), and the default/archive-mastering path is OFF. The determinism pins (T12) use OFF for exactness; add a note in T12 if a smoothing-ON determinism pin (run-to-run only) is wanted.

```swift
// Sources/FlameFlock/ArchiveRenderer.swift
import Foundation
import AVFoundation
import FlameKit
import FlameExport

public struct ArchiveRenderer {
    public init() {}

    // MARK: - FramePlan construction (§4.1, I9)

    /// 1-segment loop plan; segment 0 is loop(A). Render range: `0..<loopFrames`.
    public static func makeLoopPlan(A: Flame, loopFrames: Int, transFrames: Int, seed: UInt64) -> FramePlan {
        var sched = Schedule(librarySize: 1, framesPerSegment: loopFrames,
                             transitionFramesPerSegment: transFrames, selector: Sequential(), seed: seed)
        return FramePlan(schedule: &sched, segmentCount: 1, flames: [A],
                         loopCycles: 1, temporalSamples: A.quality.temporalSamples)
    }
    /// 2-segment edge plan; segment 0 = loop(A) (NOT rendered), segment 1 = transition(A→B).
    /// Render range: `loopFrames..<(loopFrames + transFrames)`. The loop-slot frames are
    /// NEVER encoded/written — the 2-segment plan exists only because Schedule requires
    /// a loop before a transition (§4.1).
    public static func makeEdgePlan(A: Flame, B: Flame, loopFrames: Int, transFrames: Int, seed: UInt64) -> FramePlan {
        var sched = Schedule(librarySize: 2, framesPerSegment: loopFrames,
                             transitionFramesPerSegment: transFrames, selector: Sequential(), seed: seed)
        // flames[A, B]: segment 1 reads flames[0]=A, flames[1]=B (fromSheep=0, toSheep=1).
        return FramePlan(schedule: &sched, segmentCount: 2, flames: [A, B],
                         loopCycles: 1, temporalSamples: A.quality.temporalSamples)
    }
    public static func loopRenderRange(loopFrames: Int) -> Range<Int> { 0..<loopFrames }
    public static func edgeRenderRange(loopFrames: Int, transFrames: Int) -> Range<Int> {
        loopFrames..<(loopFrames + transFrames)
    }

    // MARK: - Render one unit → archive file + thumb + tags

    /// Render a loop artifact (self-edge) into `out` (HEVC .mov) + `.jpg` thumb, then
    /// upsert the catalog row. Atomic: temp → rename → upsert. `coordinator` is the
    /// ExportCoordinator whose `renderSegmentRange` we drive (single-sourced dispatch).
    public func renderLoop(
        A: Flame, aGen: String, aId: String, shard: ShardSpec,
        settings: ExportSettings, coordinator: ExportCoordinator,
        catalog: FlockCatalog, backend: ExportCoordinator.Backend, useOffMainMetal: Bool,
        flockRoot: URL, sourceSha: String?
    ) async throws {
        let seed = FlockSeed.seed(shard: shard.name, aGen: aGen, aId: aId, bGen: aGen, bId: aId)
        let out = try FlockNaming.archiveFileURL(flockRoot: flockRoot, shardDir: shard.name,
                                                 aGen: aGen, aId: aId, bGen: aGen, bId: aId, ext: "mov")
        let params = makeParams(A: A, shard: shard, seed: seed, settings: settings)
        let plan = Self.makeLoopPlan(A: A, loopFrames: shard.loopFrames,
                                     transFrames: shard.transFrames, seed: seed)
        let range = Self.loopRenderRange(loopFrames: shard.loopFrames)

    static func qualityRank(spp: Int, temporal: Int, smoothingHw: Int) -> Double {
        Double(spp) * Double(temporal) * (Double(2 * smoothingHw + 1)).squareRoot()

    static func makeMetadata(stem: String, shard: ShardSpec, settings: ExportSettings,
                             seed: UInt64, sourceSha: String?) -> [AVMetadataItem] {
        var items: [AVMetadataItem] = []
        func custom(_ key: String, _ value: String) {
            let m = AVMutableMetadataItem()
            // mdta is the ONLY keyspace that persists custom tags to .mov — a
            // literal "emberweft" keyspace is silently dropped by AVAssetWriter
            // (verified in T1 / MetadataRoundTrip). Apple's own convention puts the
            // namespace in the KEY (com.apple.quicktime.*); emberweft.* follows it.
            m.keySpace = AVMetadataKeySpace(rawValue: "mdta")
            m.key = key as NSString
            m.value = value as NSString
            items.append(m)
        }
        let title = AVMutableMetadataItem()
        // commonKey is get-only on the macOS 26 SDK; set via the .common keyspace.
        title.keySpace = .common
        title.key = AVMetadataKey.commonKeyTitle.rawValue as NSString
        title.value = stem as NSString
        title.extendedLanguageTag = "und"
        items.append(title)
        custom("emberweft.spp", String(settings.samplesPerPixel))
        custom("emberweft.ts", String(settings.temporalSamples))
        custom("emberweft.smoothing", settings.smoothingAlpha < 1.0 ? "auto" : "off")
        custom("emberweft.smoothing_hw", String(TemporalSmoothing.halfWidth(forAlpha: settings.smoothingAlpha)))
        custom("emberweft.quality_rank", String(qualityRank(spp: settings.samplesPerPixel,
                temporal: settings.temporalSamples,
                smoothingHw: TemporalSmoothing.halfWidth(forAlpha: settings.smoothingAlpha))))
        custom("emberweft.source_sha", sourceSha ?? "")
        custom("emberweft.seed", String(seed))
        custom("emberweft.rendered", ISO8601DateFormatter().string(from: Date()))
        custom("emberweft.shard", shard.name)
        return items
```

```swift
import Foundation
import FlameKit
import FlameExport

public struct StitchRequest: Sendable {
    public let shard: ShardSpec
    public let orderedFlames: [(gen:String,id:String,flame:Flame)]   // alternating source ids per segment endpoint
    public let settings: ExportSettings
    public let flockRoot: URL
    public let out: URL
    public init(shard:ShardSpec, orderedFlames:[(gen:String,id:String,flame:Flame)],
                settings:ExportSettings, flockRoot:URL, out:URL) {
        self.shard=shard; self.orderedFlames=orderedFlames; self.settings=settings; self.flockRoot=flockRoot; self.out=out
    }
}
public enum StitchUIProgress: Sendable, Equatable {
    case resolving, plan(hitCount: Int, missCount: Int), running(hit: Int, generated: Int)
    case completed(out: URL), failed(String), cancelled
}

public actor StitchCoordinator {
    private let catalog: FlockCatalog; private let renderer: ArchiveRenderer
    private let backend: ExportCoordinator.Backend; private let useOffMainMetal: Bool
    private var cancelled = false
    public init(catalog: FlockCatalog, renderer: ArchiveRenderer,
                backend: ExportCoordinator.Backend, useOffMainMetal: Bool) {
        self.catalog=catalog; self.renderer=renderer; self.backend=backend; self.useOffMainMetal=useOffMainMetal
    }
    public func cancel() async { cancelled = true }

    public func stitch(_ request: StitchRequest,
                       coordinator: ExportCoordinator) -> AsyncThrowingStream<StitchUIProgress, Error> {
        AsyncThrowingStream { continuation in
            Task { [self] in
                if request.orderedFlames.isEmpty { continuation.yield(.failed("Sequence is empty.")); continuation.finish(); return }
                continuation.yield(.resolving)
                // 1. Build the alternating loop/edge key list: loop(A), edge(A→B), loop(B), …
                //    Each key = (shard.name, aGen,aId,bGen,bId). Loops are self-edges.
                let keys = buildSegmentKeys(request)
                // 2. ONE batched catalog lookup (no N+1): existing = catalog.batchLookup(keys)
                let existing = try await catalog.batchLookup(keys)
                let present = Set(existing.map { "\($0.aGen)|\($0.aId)|\($0.bGen)|\($0.bId)|\($0.shard)" })
                let hitCount = keys.filter { present.contains(keyString($0)) }.count
                let missCount = keys.count - hitCount
                continuation.yield(.plan(hitCount: hitCount, missCount: missCount))
                // 3. Codec-uniformity gate: every existing row.codec == shard.codec (else refuse).
                if existing.contains(where: { $0.codec != request.shard.codec }) {
                    continuation.yield(.failed("Archive shard has mixed codecs. Run 'flock rebuild'.")); continuation.finish(); return
                }
                // 4. Per segment: HIT ⇒ collect file URL; MISS ⇒ renderIntoArchive then collect.
                var urls: [URL] = []; var generated = 0, hit = 0
                for (i, key) in keys.enumerated() {
                    if cancelled { continuation.yield(.cancelled); break }
                    // Match the batch-lookup row for THIS key by the full PK tuple.
                    if let row = existing.first(where: { $0.aGen == key.aGen && $0.aId == key.aId && $0.bGen == key.bGen && $0.bId == key.bId && $0.shard == key.shard }) {
                        hit += 1
                        urls.append(request.flockRoot.appendingPathComponent(row.file))
                    } else {
                        // Render this segment into the archive first (Path-A-style), then collect.
                        try await renderSegment(forKey: key, request: request, coordinator: coordinator)
                        generated += 1
                        let row = try await catalog.lookup(aGen:key.aGen,aId:key.aId,bGen:key.bGen,bId:key.bId,shard:key.shard)!
                        urls.append(request.flockRoot.appendingPathComponent(row.file))
                    }
                    continuation.yield(.running(hit: hit, generated: generated))
                }
                // 5. Single-genome (loop-only, one file): copy, no concat. `try` (not
                // `try?`) — a copy failure must surface, not swallow.
                if urls.count == 1 { try FileManager.default.copyItem(at: urls[0], to: request.out); continuation.yield(.completed(out: request.out)); continuation.finish(); return }
                // 6. Passthrough concat (the load-bearing call — single-sourced in ExportCoordinator).
                try await coordinator.concat(segments: urls, container: .mov, to: request.out)
                continuation.yield(.completed(out: request.out)); continuation.finish()
            }
        }
    }

    // Helpers: buildSegmentKeys, keyString, renderSegment (delegates to renderer.renderLoop/renderEdge).
    private func buildSegmentKeys(_ r: StitchRequest) -> [(aGen:String,aId:String,bGen:String,bId:String,shard:String)] {
        var out: [(String,String,String,String,String)] = []
        let fs = r.orderedFlames
        for i in 0..<fs.count {
            let a = fs[i]
            out.append((a.gen, a.id, a.gen, a.id, r.shard.name))   // loop(fs[i])
            if i + 1 < fs.count { let b = fs[i+1]; out.append((a.gen,a.id,b.gen,b.id,r.shard.name)) } // edge(i→i+1)
        }
        return out
    }
    private func keyString(_ k:(aGen:String,aId:String,bGen:String,bId:String,shard:String)) -> String {
        "\(k.aGen)|\(k.aId)|\(k.bGen)|\(k.bId)|\(k.shard)"
    }
```

```swift
/// Used (a) as a selection oracle and (b) by ListXmlExporter to recover the real ES
/// edge_id (lowest on the 364 duplicate pairs; §9, I6).
public final class EdgePairsOracle: @unchecked Sendable {
    private let conn: SQLiteConnection
    public init(url: URL) throws {
        // Read-only open (SQLITE_OPEN_READONLY) — the oracle issues SELECTs only and
        // must never risk writing the ES archive edges.sqlite.
        self.conn = try SQLiteConnection(url, readOnly: true)
    }
    /// Lowest `edge_id` for an exact ordered pair, or nil if absent / cross-gen.
    public func edgeId(aGen:String,aId:String,bGen:String,bId:String) throws -> String? {
        let cur = try conn.query("""
            SELECT MIN(CAST(edge_id AS INTEGER)) FROM edge_pairs
            WHERE a_gen=? AND a_id=? AND b_gen=? AND b_id=?
            """, [aGen,aId,bGen,bId])
        if cur.next() && !cur.isNull(0) { return String(format: "%05d", cur.int(0)) }
        return nil
    }
}
```

```swift
import Foundation
import FlameKit
import FlameExport
import FlameFlock      // NEW dependency on FlameFlock (T5 threads it into EmberweftUI)

@MainActor
@Observable
public final class FlockModel {
    public enum GenerateUIState: Equatable { case idle, resolving, running(skip:Int,render:Int,total:Int), completed(rendered:Int,skipped:Int), failed(String), cancelled }
    public enum StitchUIState: Equatable { case idle, resolving, plan(hit:Int,miss:Int), running(hit:Int,generated:Int), completed(URL), failed(String), cancelled }
    public enum BrowseUIState: Equatable { case loading, loaded(FlockSnapshot), empty, failed(String) }

    public private(set) var generateState: GenerateUIState = .idle
    public private(set) var stitchState: StitchUIState = .idle
    public private(set) var browseState: BrowseUIState = .loading

    // Coordinator seams (mirror ExportManager.coordinatorFactory — testable).
    // ExportManager holds `private var coordinator: (any ExportCoordinating)?` (ExportManager.swift:179)
    // and reacquires it per run via `coordinatorFactory` (line 212). FlockModel mirrors
    // that: hold the live coordinator so cancel() can reach the actor's flag.
    internal var generateFactory: (...) -> GenerateCoordinator = { … }
    internal var stitchFactory: (...) -> StitchCoordinator = { … }
    private var generateTask: Task<Void, Never>?
    private var generateCoord: GenerateCoordinator?   // held for cancel (M4 teardown)
    private var stitchCoord: StitchCoordinator?

    public init() {}

    public func generate(_ request: GenerateRequest) async {
        if request.units.isEmpty { generateState = .failed("No genomes to generate from."); return }
        generateState = .resolving
        let gen = generateFactory(…)
        generateCoord = gen
        generateTask = Task { [weak self] in
            // weak self is fine for the iteration; cancelGenerate captures self strongly.
            do {
                for try await p in gen.generate(request, coordinator: self?.makeExportCoordinator()) {
                    await MainActor.run { self?.apply(p) }
                }
            } catch { await MainActor.run { self?.generateState = .failed(String(describing: error)) } }
        }
        await generateTask?.value
    }
    public func cancelGenerate() {
        // M4 §13.2 teardown safety: cancel BOTH the structured Task (propagates
        // CancellationError into the stream iteration) AND the coordinator actor's
        // own `cancelled` flag (the actor's loop checks `self.cancelled`, which a
        // bare Task.cancel does NOT set — the actor is a separate isolation domain).
        // The strong-self capture here is deliberate: it keeps FlockModel alive
        // until the coordinator acknowledges stop, so a sheet dismissal cannot
        // orphan a GPU-running actor.
        generateTask?.cancel()
        let coord = generateCoord
        Task { await coord?.cancel() }
    }
    public func stitch(_ request: StitchRequest) async { /* same shape */ }
    public func refreshBrowse() async { /* hop to catalog.snapshot(); set loaded/empty/failed */ }

    private func apply(_ p: GenerateUIProgress) {
        switch p {
        case .resolving: generateState = .resolving
        case .running(let s, let r, let t): generateState = .running(skip: s, render: r, total: t)
        case .completed(let rendered, let skipped): generateState = .completed(rendered: rendered, skipped: skipped)
        case .failed(let m): generateState = .failed(m)
        case .cancelled: generateState = .cancelled
        }
    }
}
```

- **Fixed T2 byte-identity pin (correctness bug).** The original AC and test compared frame-0 pixels decoded from a lossy video file (H.264/HEVC/ProRes) against a raw CPU render, asserting "byte-identical." Video decode of ANY lossy codec is never byte-exact (quantization on round-trip), so the pin would always fail. Replaced with an architectural pin: `renderSegmentRange` calls the SAME `private func renderFrames` (ExportCoordinator.swift:254) that `runJob` uses, so pre-encode frames are byte-identical by construction.
